Library

A library is one shelf of assets — images, decks, recordings, readings — that more than one course can point at. Creating one here records the shelf; files go into it through the storage host, so a shelf that exists and holds nothing says so.

Where it is used

A classroom that needs a file from a shelf names the library and the asset; the generator writes that reference into the spec instead of embedding a copy, so replacing an asset updates every course that draws on it.
