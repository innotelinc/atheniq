# Changelog — OnTrak Class (AthenIQ classroom host)

## 2.0.0 — 2026-10-24

The family re-baseline. The classroom host at `classroom.innotel.us` — generated
multi-agent lessons, validated classroom specs, the generation console, signed
completion certificates and the identity-free hand-off from OnTrak ITS — is now
**2.0.0**.

Next: completion handoff to ITS (2.1), instructor authoring (2.2), progress
analytics (2.3), versioned classroom packs (2.4), a multi-course academy (3.0) and
an adaptive classroom (4.0). No code changed in this release. See
[roadmap.md](roadmap.md); the AthenIQ platform's own roadmap is in
[../README.md](../README.md).

## 0.1.0

The classroom host as it first shipped: OpenMAIC lessons behind the family's SSO,
generated from a course's modules and linked from the training range.
