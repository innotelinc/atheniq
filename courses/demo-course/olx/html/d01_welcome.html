Welcome to the AthenIQ Demo Course

This is the platform's reference course. It exercises the components a real course is built from — text, media, every common problem type, grading, and certificates — so operators and authors can see the Open edX engine working end to end on AthenIQ's stack.

What this course demonstrates

  • Content — rich text, images, links, and embedded video.
  • Assessment — multiple choice, checkboxes, dropdowns, numerical, text, and math-expression problems.
  • Grading — weighted homework and a final exam.
  • Credentials — an automatic certificate on a passing grade, signed through Signara.

Why a demo course matters

When the LMS is upgraded, a theme is changed, or SSO is re-wired, the quickest way to prove the whole chain still works is to run one learner through this course and watch a certificate come out the other side.

Note: this course is intentionally short and public. Treat it as a wiring diagram, not as a curriculum.
