Images & Links

Images are uploaded as course assets and referenced from a text component; links connect the course to the rest of the platform.

Using images

  • Upload the file in Studio under Assets and copy the asset URL.
  • Always set descriptive alt text — screen readers and search both depend on it.
  • Keep files small; PNG for diagrams and UI, JPEG or WebP for photographs.
