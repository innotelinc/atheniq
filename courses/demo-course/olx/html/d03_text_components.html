Text Components

A text (HTML) component is the workhorse of every course. The Open edX text editor renders the HTML you give it, so headings, lists, tables, and callouts all work.

Formatting you can rely on

  • Bold, emphasis, and inline code.
  • Ordered and unordered lists.
  • Tables for structured reference material.
  • Block quotes and horizontal rules.

Writing for learners

Short paragraphs, one idea each. Lead with what the learner must do, then explain why.

Accessibility matters: use real headings in order, give every image alt text, and never rely on colour alone to convey meaning.
