Endpoint & Network Defense

Defense in depth assumes any single control can fail, so controls are layered so that one failure is not enough.

Endpoint controls

  • EDR / antivirus — detections, quarantines, and useful telemetry.
  • Host firewalls — default deny inbound; allow only what is needed.
  • Disk encryption — protects data on a lost device.
  • Application allow-listing — the strongest anti-malware control where it is practical.
  • Patching — the highest-value activity on any network.

Network controls

  • Firewalls and ACLs — allow-list traffic between zones.
  • IDS/IPS — detect and block known attack patterns.
  • Segmentation — keep servers, users, IoT, and guests apart.
  • DNS filtering — block known-malicious domains.
  • VPN / zero trust — authenticate and authorise every path, not just the perimeter.

Hardening basics

  1. Remove or disable what you do not need.
  2. Change default credentials and disable default accounts.
  3. Turn on central logging and forward it off the host.
  4. Apply a baseline image, then patch it.

Track coverage: which endpoints have EDR, which servers are patched, which firewall rules nobody can justify. Defence is measured, not assumed.
