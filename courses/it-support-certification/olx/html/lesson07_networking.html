Networking Basics

Networks are layers. Problems live at one layer, so diagnose layer by layer instead of guessing.

The four-layer model

  • Link — the physical connection: cable, Wi-Fi radio, switch port.
  • Internet (IP) — addressing and routing between networks.
  • Transport (TCP/UDP) — reliable streams (TCP) or fast datagrams (UDP), identified by ports.
  • Application — HTTP, DNS, SMTP, and the apps themselves.

Core devices

  • Switch — connects devices in one network.
  • Router / gateway — forwards traffic between networks, usually to the internet.
  • Access point — puts Wi-Fi on the network.
  • Firewall — allows or blocks traffic by rule.

A fast connectivity check

  1. Is the Wi-Fi or cable connected? Check the link light or signal.
  2. Do you have an IP address? (ipconfig / ip a)
  3. Can you reach the gateway? ping the default gateway.
  4. Can you resolve a name? ping a hostname, then a public IP.
  5. Can you reach the service? Try the browser and the app.

Whichever step fails first is your layer. That is where you start.
