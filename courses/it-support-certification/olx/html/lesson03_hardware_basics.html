Hardware Basics

A computer is a set of buses and chips that move data between storage, memory, and the CPU. Knowing the pieces lets you isolate a fault to one of them.

Core components

ComponentRoleCommon failure symptom
CPUExecutes instructionsOverheating, freezes under load
RAMWorking memory for running programsRandom crashes, BSOD, POST beeps
Storage (SSD/HDD)Persistent dataSlow boot, clicking noises, boot failure
MotherboardConnects everythingNo power, dead ports
PSUConverts AC to DCNo power, sudden shutdowns
GPURenders graphicsArtifacts, no display

Boot order and POST

On power-on the firmware (BIOS/UEFI) runs a Power-On Self-Test, then reads the boot device, then hands control to the operating system. Most "won't turn on" tickets are decided in those first seconds — a fan that never spins points at power; beeps or a debug LED point at memory, video, or the board.

Expansion and ports

  • USB — peripherals, storage, charging. USB-C is reversible and carries data, video, and power.
  • HDMI / DisplayPort — video and audio. Check the source input before condemning a monitor.
  • PCIe — internal cards such as GPUs and network adapters.
  • M.2 / SATA — internal storage.

Safe handling

Power down and unplug before opening a case. Use an anti-static strap or touch bare metal to discharge yourself. Keep liquids away and photograph the layout before you remove anything.
