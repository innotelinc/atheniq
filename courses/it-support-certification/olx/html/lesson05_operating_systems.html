Operating Systems

The operating system manages hardware, schedules programs, and provides the file system and user interface. Support work is largely operating-system work.

The three families you will meet

  • Windows — the dominant corporate desktop. Familiarity with Settings, Task Manager, Disk Management, Event Viewer, and the command prompt is essential.
  • macOS — Unix-based. Key tools are System Settings, Activity Monitor, Disk Utility, and Terminal.
  • Linux — servers and increasingly desktops. Learn the shell, package management, file permissions, and `systemd` services.

Files, paths, and permissions

Windows uses drive letters (C:\Users\name) and NTFS permissions. macOS and Linux use a single root tree (/home/name) and POSIX permissions (rwx). "Permission denied" almost always means the account lacks rights to the file or the folder above it.

Processes and performance

A slow computer is usually constrained in one of four resources: CPU, memory, disk, or network. Open the task manager or top, sort by consumption, and identify which resource is saturated before you change anything.

Updates and lifecycle

Security updates close known vulnerabilities and should be applied on a schedule. Know when each operating system reaches end of support: an unsupported OS cannot be made secure and must be upgraded or replaced.

Useful commands

  • ipconfig /all (Windows) or ip a (Linux/macOS) — network config
  • ping, tracert/traceroute — reachability
  • sfc /scannow (Windows) — repair system files
  • df -h, du -sh — disk usage
