Cleaning & Shaping Data

Cleaning is not the boring part before the real work — it is the work. Analysis is only as trustworthy as the table underneath it, and the same cleaning questions come back on every dataset.

Six dimensions of quality

DimensionThe question
CompletenessAre the required values present?
AccuracyDoes the value match the world?
ConsistencyIs the same thing written the same way everywhere?
UniquenessIs each entity recorded once?
TimelinessIs it current enough to act on?
ValidityDoes it obey the rules (ranges, formats, codes)?

A repeatable cleaning pass

  1. Profile — count rows, count blanks, list distinct values in each categorical column. Look before you touch.
  2. Standardise the shape — trim whitespace, fix capitalisation, one format per date, one unit per measure.
  3. Handle duplicates — decide what makes a record unique, then keep one. Record how many you dropped.
  4. Handle missing values — an empty cell, a zero, and "unknown" mean three different things. Never let a tool turn one into another.
  5. Validate — ranges, allowed codes, date sanity. Flag, do not silently delete.
  6. Document — keep the original, keep the steps, and write down every judgement call you made.

Outliers and recoding

An outlier is a question, not an error: a bad entry, a genuine extreme, or a different population mixed into the same table. Investigate before you remove anything, and if you remove it, say so. Recode categories only where the mapping is unambiguous — "UK", "U.K." and "United Kingdom" are one place; "Georgia the country" and "Georgia the state" are not.

Keep the raw file untouched. Cleaning is a recipe you can re-run, not an edit you make once.
