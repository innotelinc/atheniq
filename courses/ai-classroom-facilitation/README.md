# MAIC101 — AI Classroom Facilitation

The core course of the Innotel Labs **AI Classroom Facilitator** track, for
instructors and trainers. It covers using generative AI well, authoring an OpenMAIC
classroom, facilitating live sessions, and assessing learners ethically.
