Facilitating Live Sessions

Running the classroom is a facilitation skill, and the AI changes only one variable — the other participants. Everything that makes a session work still comes from you.

Before

  • Brief the learners: what the session is, what their role is, how long it runs.
  • Test the run end to end on the real material — agents misread prompts that looked fine.
  • Have a plan B: a static version of the activity if the model gateway or the classroom is unavailable.
  • State the AI-use policy for the session up front.

During

  1. Frame — state the goal and the success criteria in one sentence.
  2. Model — show one interaction before handing over.
  3. Circulate — watch for learners who are stuck, bored, or off-task, and intervene early.
  4. Keep the humans talking — the AI is a foil, not the lesson. Pause it to discuss, question, or correct it.
  5. Capture — note misconceptions and good moments for the debrief.

Managing the failure modes

HappensDo
The AI states something falseStop, make it a teaching moment — ask the group to check it against the source
The agent breaks characterCorrect it in the open; learners learn more from the recovery
Dominant voices take overAssign roles explicitly and rotate
A learner is uncomfortable with AIOffer an equivalent non-AI path — no learner is required to interact with it

After

Debrief against the success criteria: what was learned, what the AI got wrong, what you would change. Note the prompt and the classroom revision that would fix the session next time — that note is the improvement.
