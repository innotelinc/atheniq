Clean, Describe, Chart, Verify

An assistant makes analysis faster at every step — and makes a confident wrong number easier to produce. The method below keeps the speed and adds the checks that make the result defensible.

1. Profile before you clean

Count rows, count distinct keys, look at nulls, look at the tails. Record what you found before changing anything: how many rows, how many blanks, how many duplicates, what the date range is. That snapshot is what lets you prove the cleaning did not change the answer.

2. Record every cleaning decision

  • Rows dropped, and why.
  • Values imputed, with the rule used.
  • Duplicates resolved, and which record was kept.
  • Units converted, and the conversion.

If a number is ever questioned, this list is the answer. "The AI cleaned it" is not.

3. Describe before you explain

Distribution, range, median, and the count in each group. A summary that starts with a percentage before anyone has seen the denominator is a trap; the denominator is often the whole story.

4. Choose the chart for the question

QuestionChart
How does it change over time?Line
How do groups compare?Bar, sorted
How is one value distributed?Histogram
Is there a relationship?Scatter

Truncated axes and dual axes can make a flat trend look dramatic. Ask whether the chart would survive being screenshotted without its caption.

5. Recompute every number that will be quoted

An assistant can state a total that does not match the table it summarized. Recompute the headline figures directly, and check that subgroup totals add to the whole. This one habit catches most AI analysis errors.

Try this

Take a summary an assistant produced from a table you have. Recompute the two most important numbers by hand or with a pivot. Then check whether the excluded rows are mentioned anywhere. Both checks take minutes and change conclusions surprisingly often.
