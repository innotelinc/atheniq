Windows Server & Directory Services

Active Directory Domain Services (AD DS) is the identity and policy backbone of a Windows network. Everything else — DNS, DHCP, file shares, Group Policy — hangs off it.

The pieces

  • Domain controller — hosts AD DS and authenticates users.
  • Organizational Units (OUs) — containers for users, computers, and groups; the unit that policy is applied to.
  • Group Policy Objects (GPOs) — settings applied to OUs: drive maps, firewall rules, password policy, software.
  • DNS — AD depends on it entirely; the domain name must resolve to the domain controllers.

Everyday administrative tasks

  1. Create a user, add them to a group, assign group-based access.
  2. Join a computer to the domain and move it to the right OU.
  3. Apply a GPO and verify with gpresult /r.
  4. Reset a password or unlock an account.

A healthy-domain checklist

  • dcdiag reports no failures.
  • DNS forward and reverse zones resolve internal names.
  • Time is synchronised — Kerberos fails if clocks drift more than five minutes.
  • Backups of System State and AD are tested, not just scheduled.
