Routing, Switching & Wireless

Switches move frames inside a network; routers move packets between networks; access points put wireless clients onto the network.

Switching and VLANs

  • A managed switch learns which MAC address lives on which port.
  • VLANs segment the network logically — separate voice, data, guest, and management traffic without separate hardware.
  • A trunk carries multiple VLANs between switches; an access port belongs to one.

Routing

A router keeps a routing table of destinations and next hops. Static routes are hand-written; dynamic protocols (OSPF, BGP) discover paths automatically. NAT rewrites private addresses to a public one so a whole LAN can share a single internet address.

Useful tools

  • ip route / route print — the routing table
  • traceroute / tracert — the path a packet takes
  • arp -a — IP-to-MAC mappings on the local segment
