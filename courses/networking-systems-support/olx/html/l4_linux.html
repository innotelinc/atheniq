Linux Server Administration

Most of the internet runs on Linux, and so does much of the platform stack. Learn the shell and the service model, and everything else follows.

Services with systemd

  • systemctl status nginx — is it running?
  • systemctl enable --now nginx — start now and on boot.
  • journalctl -u nginx -f — follow its logs.

Packages

  • Debian/Ubuntu: apt update && apt upgrade
  • RHEL family: dnf install

Users, groups, and permissions

CommandPurpose
useradd / usermodManage accounts
chmod / chownPermissions and ownership
sudoRun one command as another user

POSIX permissions read as rwx for owner, group, and other. Prefer groups and sudo over shared root logins.

Remote access and safety

  • Connect over SSH keys, not passwords, and disable password login for root.
  • Keep the firewall on: ufw or firewalld, default deny.
  • Patch on a schedule and watch disk with df -h.
